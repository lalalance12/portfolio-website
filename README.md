# Portfolio Website - Xerxes Lance Lompon

A modern, high-performance portfolio showcasing my work as a Software Engineer specializing in full-stack development, AI/ML, and cloud technologies.

## 🎯 Overview

This portfolio demonstrates my expertise in building scalable production systems. Recently developed an AWS-hosted publication platform and an MVP for a healthcare workflow system using React, Next.js, Laravel, AWS, Tailwind, and Supabase.

**Live Site:** [xerxeslompon.com](https://xerxeslompon.com)

## ✨ Key Features

- **Smooth Animations** - Framer Motion powered transitions and scroll effects
- **Responsive Design** - Optimized for all devices from mobile to desktop
- **Interactive Elements** - Dynamic project filtering, animated navigation, hover effects
- **Resume Download** - Direct PDF download functionality
- **Contact Integration** - Email, phone, and LinkedIn integration with copy-to-clipboard
- **SEO Optimized** - Complete meta tags, Open Graph, and structured data
- **Performance** - Throttled scroll handlers, error boundaries, lazy loading
- **Accessibility** - ARIA labels, semantic HTML, keyboard navigation

## 🛠️ Built With

**Frontend:**
- [Next.js 15](https://nextjs.org) - React framework with App Router
- [React 19](https://react.dev) - UI library
- [TypeScript](https://www.typescriptlang.org) - Type safety
- [Tailwind CSS v4](https://tailwindcss.com) - Styling framework
- [Framer Motion](https://www.framer.com/motion/) - Animation library

**Design & UX:**
- Custom scroll-based animations
- Parallax effects
- Smooth section navigation
- Mobile-first responsive design
- Custom animated components

**Performance & SEO:**
- Server-side rendering
- Optimized images with next/image
- Lazy loading components
- Custom throttle utilities
- Sitemap and robots.txt
- Schema.org structured data
